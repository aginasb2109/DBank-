Running the Project Locally
To test the application locally, use the following commands:

bash
Copy
Edit
# Start the replica in the background
dfx start 

# Deploy your canisters to the replica
dfx deploy
After deployment, your application will be available at http://localhost:8000?canisterId={asset_canister_id}.

For frontend changes, start the development server with:

bash
Copy
Edit
npm start
This will start a server at http://localhost:8080, proxying API requests to the replica at port 8000.

Frontend Environment Variables
If you are hosting frontend code outside DFX, ensure the project doesn't fetch the root key in production:

Set NODE_ENV to production if using Webpack.

Use your own method to replace process.env.NODE_ENV in autogenerated declarations.
